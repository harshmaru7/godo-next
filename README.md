# godo-next

Auto-generated Go SDK for DigitalOcean. Everything below this README
(once regen runs) is emitted by [Fern](https://buildwithfern.com/) via
the pipeline in [`harshmaru7/sdk-pipeline`](https://github.com/harshmaru7/sdk-pipeline).

**Do not hand-edit.** Changes will be overwritten by the next regen.
To change behavior, change the spec in `openapi-sdk` or the generator
config in `sdk-generator` and rerun.

## How it gets regenerated

- A PR merging to `harshmaru7/openapi-sdk` fires a `repository_dispatch`
  to this repo.
- `.github/workflows/regen.yml` calls the reusable workflow in
  `harshmaru7/sdk-pipeline`, which runs Fern and opens a PR back to
  this repo with the new code.
- Manual trigger: GitHub UI → Actions → "regenerate" → Run workflow.
